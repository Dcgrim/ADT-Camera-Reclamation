3. Pocket reference

/adm/enable_ui.cgi — enable admin UI

/adm/get_group.cgi — list groups

/adm/get_ui_group.cgi — list UI groups

/adm/get_group.cgi?group=NAME — read group

/adm/set_group.cgi?group=NAME&SETTING=VALUE — change setting

Typical workflow: connect camera to TP-Link, identify its current IP and MAC, authenticate, enable the UI, and open the main camera page.
